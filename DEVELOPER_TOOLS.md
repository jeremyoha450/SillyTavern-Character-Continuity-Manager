# CCM Developer Mode

Developer Mode is a persisted visibility toggle under Debug / Logging. It defaults off and does not alter AI, automation, or migrations.

Its current area is descriptive text only. Database Inspector and AI Context Viewer are not implemented and are not being worked on. The existing debug JSON export is not a combined Safe Debug Bundle. AI Benchmark and Recovery Tools remain deferred. No placeholder buttons should be added.

Developer Mode alone exposes no private content. Separately enabled AI-content capture can contain private data and remains explicitly warned and bounded.
